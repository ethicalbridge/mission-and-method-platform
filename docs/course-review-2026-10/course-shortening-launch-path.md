# Courses for entrepreneurs: how to make them shorter

Review of the four entrepreneurs' courses (modules 100 to 110, loaded from `course-data.js`), October 2026. Recommendations only; no files were changed.

## The short answer

| | Today | Proposed core path ("Launch Path") | Moved to "When you grow" | Cut |
|---|---|---|---|---|
| Lessons and recaps | 111 (100 taught + 11 recaps) | **58** (47 taught + 11 recaps), 52% | 17 lessons (about 5.7 h, optional) | 3 lessons (their useful parts go elsewhere) |
| Hours | 36.3 h | **about 21.5 h** | | |

How it gets there:

1. **Merge lessons that fill in the same table or answer the same question** (33 lessons absorbed into 26 merged lessons). Example: the Theory of Change takes 7 lessons to fill one 7-column table, one column at a time. Four lessons do the same job.
2. **Move lessons a new initiative does not need until a trigger appears** (first salary, first restricted grant, registration, a board) to an optional "When you grow" shelf. Every moved lesson gets a trigger, so the learner knows when to come back.
3. **Cut three lessons that repeat other lessons** (5.5, 8.12, 10.8) and keep their few useful lines elsewhere.
4. **Let templates do the legal teaching.** Module 10 already has nine 20-minute lessons with no exercise that each end in template links. These become two lessons.
5. **Recaps stay** (they produce the module PDFs that make up each Pack) but drop from 15 to 10 minutes.

Nothing a funder, bank or partner would ask for leaves the four Packs. The few items that move (pay bands, reserves policy, evaluation plan, financial reporting calendar) are either covered by a template or brought back by a clear trigger. See "Pack check" at the end.

Timing note: almost every lesson is set to 20 minutes whatever its length (8.10 has 265 words, 2.2 has 855). The estimates below use 20 minutes for a single lesson, 25 to 30 for a merged one and 35 at most, so they stay comparable with today's numbers.

Key: **KEEP** = stays in the core path as it is. **MERGE** = becomes part of the lesson named. **MOVE** = optional "When you grow" lesson, with a trigger. **CUT** = remove the lesson; the useful lines go where stated.

## Notes for whoever makes the change

- `course/adapt.js` copies the organisation module's structure exactly and throws if an entrepreneurs' lesson has no matching base lesson or no text. Merging or moving founder lessons needs a small extension, for example a `drop` list and a `merge` map per module, so the e-files can diverge from the m-files.
- The redirect pattern already exists (`m.merged={vision:'purpose',mission:'purpose'}` in `course/e01-strategic-foundations.js`). Use the same for every absorbed lesson so saved answers and old links still work; keep the absorbed lesson's field keys in the host lesson where possible.
- Lesson pages are generated by `scripts/generate-lesson-pages.mjs`; it must be rerun after renaming or removing lessons.
- Public numbers ("111 lessons", "about 36 hours", "21 lessons ~7h" and so on) appear in `courses-entrepreneurs.html` and the `course-entrepreneurs-*.html` pages and would need updating.
